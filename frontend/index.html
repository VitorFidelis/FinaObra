Sobre o FinaObra

FinaObra é uma plataforma moderna desenvolvida para simplificar a gestão de custos na construção civil.

Integrada à API Spring Boot com autenticação padrão Bearer Token e isolamento por conta de usuário.

Versão: 1.0.0 Tecnologias: HTML5 • CSS3 • JS Vanilla
